# FORGEFIT — Gym & Fitness Website

FORGEFIT is a modern, responsive gym and fitness website built using HTML, CSS, and JavaScript.

## Features
- Modern dark-themed design
- Responsive desktop and mobile layout
- Workout programs section
- Trainer profiles
- Membership plans
- Fitness gallery
- Testimonials
- WhatsApp integration for enquiries

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Purpose
This project was created for learning and practicing frontend web development.

## Author
Created as a personal web development portfolio project.
